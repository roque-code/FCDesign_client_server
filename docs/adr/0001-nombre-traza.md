# ADR 0001: Nombre de trabajo Traza

## Estado

Aceptado.

## Contexto

El producto necesita un nombre propio, distinto del de otras herramientas de pseudocódigo. El directorio del repositorio se llama `fcdesign` y puede seguir así.

## Decisión

El nombre de trabajo del producto es Traza. El paquete del lenguaje se llama `language_core`. Ni la interfaz ni los mensajes copian la marca, los textos ni los iconos de otra aplicación.

## Consecuencias

Los títulos visibles usan Traza. Cambiar el nombre más adelante no obliga a renombrar módulos. Hace falta confirmación antes de diseñar logotipo, dominio o el título de la ventana.
