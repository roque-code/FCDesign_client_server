# ADR 0001: Nombre del producto

## Estado

Aceptado.

## Contexto

El producto necesita un nombre propio, distinto del de otras herramientas de pseudocódigo. El directorio del repositorio se llama `fcdesign` y puede seguir así.

## Decisión

El nombre del producto es Aulivana-FCDdesign. El paquete del lenguaje se llama `language_core`. Ni la interfaz ni los mensajes copian la marca, los textos ni los iconos de otra aplicación.

## Consecuencias

Los títulos visibles usan Aulivana-FCDdesign. El esquema de la aplicación de escritorio es `Aulivana-FCDdesign:`. Cambiar el título no obliga a renombrar módulos, la base ni las claves internas.
